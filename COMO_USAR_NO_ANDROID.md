# 📱 Como Usar no Android

## ✅ Método Mais Fácil (Sem Instalação)

### 1. Baixar o arquivo
- Acesse: https://github.com/limawilker2019-code/rover-finance-android
- Clique no arquivo `web-app.html`
- Clique no botão **"Download raw file"** (ícone de download) ou copie o link

### 2. Abrir no Navegador do Android

**Opção A - Via Chrome/Firefox:**
```
1. Salve o arquivo na pasta "Downloads"
2. Abra o navegador (Chrome, Firefox, etc)
3. Digite na barra de endereços: file:///storage/emulated/0/Download/web-app.html
4. Pronto! 🎉
```

**Opção B - Compartilhar via WiFi:**
```
1. No PC: Use uma ferramenta como "Live Server" ou "Python Simple Server"
2. No Android: Acesse o IP do PC no navegador
3. Exemplo: http://192.168.1.100:8000
```

### 3. Salvar como App (Opcional)

No Chrome do Android:
1. Abra a página
2. Toque em **⋮** (3 pontos) → "Instalar app" ou "Adicionar à tela inicial"
3. O app vai funcionar como app nativo!

## 📊 Backup de Dados

### Exportar
1. Vá em Configurações
2. Clique em "📥 Exportar Dados"
3. Arquivo será salvo como JSON
4. Compartilhe ou guarde em segurança

### Restaurar
- Seus dados são automaticamente salvos no navegador
- Nunca limpe o cache do aplicativo sem fazer backup!

## 🔧 Troubleshooting

**Problema: Não consigo abrir o arquivo**
- Verifique se está em `Downloads`
- Tente copiar o caminho exato
- Use Chrome ao invés de Firefox

**Problema: Os dados desapareceram**
- Não limpe o cache do navegador
- Exporte seus dados regularmente
- Use a mesma app para evitar perda de dados

**Problema: Quer mudar de telefone?**
- Exporte os dados antes
- Abra a app no novo telefone
- Veja como importar abaixo
